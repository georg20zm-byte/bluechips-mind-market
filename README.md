# Blue Chips: Mind Market

PvP prediction-market auto-battler · Telegram Web App
Тёмная тема `#07080B` · циан `#38E1EA` · золото `#F0BE3C` · JetBrains Mono + Manrope

## Структура

```
index.html                  разметка + подключение модулей
css/style.css               все стили
js/00-state-market.js       валюты, уровень игрока, события, ставки, магазин
js/01-portfolio.js          конструктор портфеля, драг, страница карты, онбординг
js/02-cards-meta.js         CARD_DB, чемпионы, коллекция/уровни, сложность ботов
js/03-tutorial.js           заскриптованный туториал (6 уроков)
js/04-engine.js             симуляция матча: юниты, башни, AI, Око, исходы
js/05-render.js             отрисовка канваса (арена, Око-линия, туториал) + loop
js/06-flow-input.js         переходы экранов, ввод (драг карт, скан, чемпион), boot
data/season-01.json         конфиг Сезона 1 (награды, категории, правила)
worker/events-parser.js     крон-воркер: Polymarket API → data/events.json
docs/prototype-*.html       монолит-референс (история прототипа, 16 итераций)
```

Модули подключаются последовательно и делят общую область видимости —
это осознанный этап: порядок файлов = порядок секций исходного монолита,
поведение идентично прототипу бит-в-бит. Перевод на ES-модули — после
стабилизации Сезона 1.

## Запуск локально

Просто открыть `index.html` в браузере, либо:

```bash
npx serve .
```

Тест на телефоне — задеплоить и открыть в Telegram WebView (см. ниже).

## Деплой (Netlify из Git)

1. Netlify → Add new site → Import from Git → выбрать этот репозиторий
2. Build command: пусто · Publish directory: `.`
3. Каждый push в `main` = автодеплой

## Воркер событий

```bash
node worker/events-parser.js   # создаст data/events.json
```

Гонять по крону раз в час (VPS systemd-timer — по образцу WB-бота, или
Cloudflare Workers Cron). Эндпоинт/поля Polymarket сверить с
https://docs.polymarket.com перед первым продовым запуском — схема могла
измениться.

## Правила дизайна (зафиксировано)

1. Никаких имба-фич: ни одно действие не выигрывает матч без контригры
2. Функция карты читается за долю секунды (лента типа, живые цифры)
3. Драг — основной жест; обучение показывает жест рукой, а не текстом
4. Награды — только победителю; прокачка гейтится уровнем игрока (потолок = ур.+2)
